# COMPLIANCE — AIGC 标识与广告合规（交付中国市场必读）

> 核对日期：2026-07-14。依据：《人工智能生成合成内容标识办法》
> （国信办通字〔2025〕2号，2025-09-01 施行）、强制性国标 GB 45438-2025
> 《网络安全技术 人工智能生成合成内容标识方法》、网标委 2025-08-28 发布的
> 6 项文件元数据隐式标识实践指南。
> **注意：网信部门已在集中查处标识违规的应用（约谈/限期整改/下架），
> 这不是纸面要求。**

## 1. 双重标识义务（显式 + 隐式，缺一不可）

**显式标识**（用户可感知）：
- 视频要求：在**视频起始画面**和视频播放周边的适当位置添加显著提示标识，
  可在末尾和中间适当位置补充；技术细则（GB 45438-2025）含持续时间、
  文字高度等量化指标（如标识持续 ≥2 秒）。
- 本仓库现状：`assembler.py` 默认在右上角烧录"AI生成"角标（整片时长）。
  上生产前对照 GB 45438-2025 原文核对字号/位置/时长的量化指标。
- 可灵 `watermark=true` 打的是"可灵AI"水印——那是**模型方**的标识，
  不能替代**我们作为服务提供者**的显式标识义务。适配器默认关闭它，
  由装配层统一打标，避免双水印。

**隐式标识**（文件元数据，不可感知）：
- 必须写入文件元数据，内容包含：**生成合成内容属性信息、服务提供者
  名称或编码、内容编号**等制作要素信息。
- 具体字段格式按网标委 6 项实践指南中的《人工智能生成合成内容标识方法
  文件元数据隐式标识》（视频文件篇）执行。
- 本仓库现状：assembler 只写了占位的 metadata comment，**不满足国标**。
  Phase 2 待办：按实践指南的 JSON 结构写入（服务提供者编码需在
  算法备案/安全评估时取得）。

**红线**：任何组织和个人不得恶意删除、篡改、伪造、隐匿标识——
交付客户时合同里写明客户不得去除标识。

## 2. 责任主体划分（和上海客户谈合同时要分清）

- **服务提供者**（生成端）：负责加显式+隐式标识；提供下载/导出功能时
  确保文件含合规标识；应用户要求提供无显式标识版本的，须在用户协议中
  明确对方标识义务，并**留存日志 ≥6 个月**。
- **传播平台**（抖音/天猫等）：自动检测并补充标注。主流平台已上线
  "AI生成"角标 + 隐式元数据功能，发布时必须主动声明 AIGC。
- 我们的产线如果是"交付成片给客户、客户自己发布"，我们承担生成端义务，
  客户承担发布端申报义务——**写进交付验收条款**。

## 3. 广告品类附加项

- 广告法禁用语（"最""第一""国家级"等绝对化用语）：已在
  `storyboard_agent._business_checks` 留了挂载位，Phase 2 加一个
  廉价 LLM 检查项，在分镜阶段拦截 dialogue / on_screen_text。
- 商品图、模特肖像、字体、BGM 的授权：合同约定由客户提供并担责；
  流水线侧的对应动作是资产登记时记录授权来源字段（可加进 `Asset` 模型）。
- 背景路人面部虚化已进负面约束库（肖像权风险）。
